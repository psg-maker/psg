세 가지 취향으로 소개합니다

01

솔직하게 말하는 사람이 좋습니다.

뒤에서 돌려 말하기보다, 불편하더라도 직접 이야기하는 관계가 더 편합니다.

피드백을 듣고 행동을 바꾸는 쪽을 선택해 왔습니다.

공개 근거 · 낯선 사람에게 먼저 말을 거는 행동을 시도했고, 지금은 먼저 대화를 시작하는 일이 이전보다 편해졌습니다.

상황 · 행동 · 결과 보기
상황
뒤에서는 불만을 말하면서 정작 당사자에게는 이야기하지 않는 관계를 겪으며 답답함을 느꼈습니다.
행동
저부터 문제가 있으면 가능한 직접 이야기하려고 했고, 제가 받은 피드백도 불편하더라도 한 번 돌아본 뒤 행동으로 옮겨봤습니다.
결과
솔직하고 자신 있게 말하는 사람과 있을 때 더 편하고, 저 역시 필요한 말을 먼저 꺼내는 편이 됐습니다.
02

성장하는 느낌을 좋아합니다.

헬스는 어제보다 조금이라도 나아진 나를 확인하는 시간이라서 좋아합니다.

큰 변화보다 작은 발전이 눈에 보일 때 가장 큰 만족을 느낍니다.

공개 근거 · “헬스 — 어제보다 발전한 나를 만나는 시간”이라는 한 문장으로 제 취향을 설명할 수 있습니다.

상황 · 행동 · 결과 보기
상황
운동은 한 번에 큰 변화가 생기기보다 작은 변화를 반복해서 확인하는 활동이라고 느꼈습니다.
행동
헬스를 할 때 이전보다 조금이라도 나아진 부분이 있는지 스스로 확인하면서 운동을 이어갑니다.
결과
작은 발전이 보일 때 성취감을 느끼고, 그 감각이 좋아서 헬스를 계속 좋아하게 됐습니다.
03

함께 맞아떨어지는 순간을 좋아합니다.

풋살에서 혼자 해결하기보다 동료와 움직임이 맞고 패스가 이어질 때 더 큰 재미를 느낍니다.

혼자 만든 결과보다 서로의 역할이 연결된 결과에 더 끌립니다.

공개 근거 · 동료와 주고받은 패스가 골로 이어지는 순간이 제가 풋살을 계속 좋아하는 가장 분명한 이유입니다.

상황 · 행동 · 결과 보기
상황
풋살은 혼자 공을 오래 갖고 있다고 좋은 기회가 생기는 경기보다 여러 사람이 함께 움직여야 공간이 열리는 순간이 많습니다.
행동
동료와 패스를 주고받고, 공이 없을 때도 다음 패스를 받을 공간을 찾아 움직이려고 합니다.
결과
패스가 연결돼 골로 이어질 때 가장 큰 즐거움을 느꼈고, 혼자 잘하는 것보다 함께 만들어낸 결과를 좋아한다는 걸 알게 됐습니다.

제출·확인 기록 펼치기

1. 대상과 공개 범위

대상·목적: SKT 알레프 강사진과 교육 동기에게 저의 경험, 취향, 가치관과 IT 학습 방향을 한 페이지로 소개합니다.

공개: 이름·나이·학력, 직무 경험, 취미·가치관, 학습 목표, 개인정보를 포함하지 않은 결과 문장.

비공개: 가족 구성원 정보, 상세 주소·개인 연락처, 건강·재정 등 깊은 사생활, 거래처·고객의 식별 정보.

외부 로그인 없음비밀번호 없음외부 API 없음

배포 확인: 이 HTML 자체는 별도 인증 없이 동작합니다. 최종 업로드 후에는 제출할 공개 주소를 새 시크릿 창에서 한 번 열어 로그인·초대·비밀번호 없이 접근되는지만 직접 확인합니다.

2. 감정·취향 3개와 근거

  • 솔직하게 말하는 사람을 좋아함 → 상황·행동·결과 + 개인정보 없는 결과 문장 연결.
  • 성장하는 느낌을 좋아함 → 헬스 경험을 상황·행동·결과로 정리하고, 개인정보 없는 결과 문장과 연결.
  • 함께 맞아떨어지는 순간을 좋아함 → 상황·행동·결과 + 풋살 경험의 결과 문장 연결.

3. 두 화면의 첫인상 검사

  • 1366×768 — 통과: 소개와 세 가지 취향 카드, 각 카드의 공개 근거가 첫 화면 안에 모두 보였고 가로 넘침은 0px이었습니다.
  • 1920×1080 — 통과: 소개와 세 가지 취향 카드, 각 카드의 공개 근거가 첫 화면 안에 모두 보였고 가로 넘침은 0px이었습니다.

4. 실제 결함 수정 기록

  • 가운데 카드의 개연성 — 수정 전: 헬스 이야기를 하다가 개발 프로젝트 근거로 넘어가 흐름이 끊김 → 수정 후: 상황·행동·결과와 공개 근거를 모두 헬스 경험으로 통일.
  • 소스 링크 — 수정 전: source.html이라는 별도 파일에 의존 → 수정 후: 현재 페이지의 HTML 소스를 브라우저에서 직접 생성하여 내려받음.
  • 제출 기록 링크 — 수정 전: submission.html이라는 별도 파일에 의존 → 수정 후: 같은 페이지의 #submission-record로 연결.
  • 내용 기준 — 수정 전: 경험 중심 3개 카드 → 수정 후: 가이드라인 문구에 맞춰 감정·취향 3개를 각각 상황·행동·결과로 재작성.

최종 검사: HTML 소스 다운로드와 제출 기록 내부 링크가 모두 동작했습니다. 브라우저 콘솔 오류 0건, 페이지 오류 0건을 확인했습니다.

가독성 검사: 본문/배경 12.14:1, 보조문구/배경 5.81:1, 강조색/카드 6.52:1, 밝은 글자/초록 배경 9.23:1로 주요 텍스트 대비가 충분했습니다.

5. 상호작용·비밀값·AI 역할

짧은 확인 방법: ① 가운데 ‘성장하는 느낌을 좋아합니다’ 카드로 이동 → ② ‘상황 · 행동 · 결과 보기’를 마우스로 누르거나 Tab으로 초점을 옮긴 뒤 Enter/Space → ③ 헬스에 대한 상황·행동·결과가 나타나고 다시 닫히면 통과. 키보드에서 열리지 않거나 내용이 보이지 않으면 실패.

실행 결과: 마우스 클릭, Enter, Space 세 방식 모두 같은 열기/닫기 동작을 수행했습니다.

비밀값 점검: 페이지에 비밀번호·토큰·API 키·개인 연락처·고객 주소를 넣지 않았습니다.
